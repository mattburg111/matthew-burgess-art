# Matthew Burgess

A simple artist website built with HTML and CSS. No dependencies or build step.

Open `index.html` in a browser, or serve this directory locally:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

Edit the individual HTML pages to add your biography, artwork, artist statement,
and contact information. Shared styling lives in `styles.css`.

To publish, upload the files to any static web host, or enable GitHub Pages for
the root of the repository once the files have been pushed.
